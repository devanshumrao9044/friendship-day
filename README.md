# Friendship Day 

Create a premium Friendship Day website from the provided images.



The website must NOT be a single-page website.



Every major section must be a separate page while keeping the same website/domain. Navigation between pages should feel smooth and natural, but each page must actually be its own page—not a hidden section, not a slide, and not a long scrolling layout.



Use the provided images intelligently throughout the website. Choose suitable images for each page automatically.



Design Style:

Premium, emotional, modern, soft pastel aesthetic with glassmorphism, beautiful gradients, handwritten typography, elegant cards, floating hearts, flowers, sparkles, subtle particles and smooth premium animations.



The website should include:

- Beautiful intro with animated envelope

- Home page

- Timeline of memories

- Photo gallery with lightbox

- Flip memory cards

- Scratch reveal cards

- Personal letters

- Music player

- Friendship mini games

- Wishes page

- Emotional ending page



Every page must contain rich animations, interactive elements, premium transitions and polished UI.



The music player should include:

- Play/Pause

- Progress bar

- Seeking

- Playlist support

- Floating mini player

- Volume control

- Proper synchronization



The gallery should support:

- Masonry layout

- Lazy loading

- Blur loading

- Zoom

- Lightbox

- Smooth transitions



The memory section should include:

- Flip cards

- Scratch cards

- Hover animations

- Mobile touch support



Performance requirements:

- Fast loading

- Lazy loading

- Optimized assets

- Debounced expensive events

- Passive listeners

- Proper cleanup of event listeners and observers

- No memory leaks



Accessibility:

- Keyboard navigation

- Proper focus states

- Semantic HTML

- ARIA labels

- Mobile friendly

- Responsive for every screen size



Code quality:

- Production ready

- Modular

- Clean architecture

- Reusable components

- Separate CSS and JavaScript files

- No duplicated logic

- No console errors

- No broken links

- No unfinished sections



If an existing project is provided:

Read the complete project first.

Modify the existing files instead of rebuilding everything.

Keep all working functionality intact.

Only improve or replace what is necessary.

Preserve compatibility with the current project.



STRICTLY AVOID:

- Single-page website

- Long scrolling layout

- Slide-based website

- Fake pages made with hidden sections

- Inline CSS

- Inline JavaScript

- Bootstrap

- jQuery

- Tailwind CDN

- React CDN

- Placeholder content

- TODO comments

- Broken buttons

- Broken links

- Console errors

- Accessibility issues

- Memory leaks

- Unoptimized images

- Removing existing features without necessity

- Changing the project structure unless absolutely required



The final result should feel like a professionally designed premium Friendship Day website with multiple real pages under one website link, flawless animations, excellent mobile experience, polished interactions, and production-quality code.
